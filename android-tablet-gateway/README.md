# Androidタブレット点数送信アプリ

麻雀卓の席1〜4の現在点数をWebアプリへ送る、最小版のAndroidアプリです。
この段階ではカメラ認識は入れず、手入力で点数送信だけを確認します。

## できること

- `deviceId` で卓情報を取得
- 席1〜4の現在点数を表示
- 席1〜4の点数を手入力
- `POST /api/android/point-update` へ点数送信
- 最終取得時刻、最終送信時刻、送信予定の点数を表示
- 縦に長い画面でもスクロールして下のボタンまで操作
- カメラプレビューを表示
- 席ごとに認識範囲を%で設定
- カメラ画像上に席1〜4の認識範囲を四角で表示
- カメラ画像上に対角線の波線を表示し、卓中心とカメラ中心を合わせやすくする
- カメラ画像から数字を読み取り、認識範囲に入った数字を席1〜4へ反映

Android側にはプレイヤー名やプレイヤーIDは表示しません。

## Android Studioで開く

1. Android Studioを起動
2. `Open` を選択
3. このフォルダを開く

```text
/Users/user/Documents/麻雀採点収集機能/android-tablet-gateway
```

4. Gradle Syncが終わったら実行

## 最初の設定

Webアプリを起動しておきます。

```bash
cd "/Users/user/Documents/麻雀採点収集機能"
npm run dev
```

同じWi-Fi上のAndroid実機からMacへ接続する場合は、アプリの `Web API URL` にMacのNetwork URLを入れます。
例:

```text
http://192.168.2.168:3000
```

Android EmulatorからMacへ接続する場合は、通常はこちらです。

```text
http://10.0.2.2:3000
```

USB接続で実機からMacへ接続する場合は、Mac側で次を実行します。

```bash
~/Library/Android/sdk/platform-tools/adb reverse tcp:3000 tcp:3000
```

その場合、アプリの `Web API URL` は次にします。

```text
http://127.0.0.1:3000
```

`端末ID` はまずこれで確認します。

```text
mock-table-1
```

## 操作手順

1. Web側で1卓に4席を設定
2. Androidアプリを起動
3. `Web API URL` と `端末ID` を確認
4. `卓情報を取得・更新` を押す
5. `カメラ読み取り開始` を押す
6. 必要に応じて席1〜4の認識範囲を調整
7. 点数表示がカメラに入るように調整
8. 席1〜4に反映された点数を確認し、必要なら手で修正
9. `点数を送信して反映` を押す
10. Webダッシュボードで1卓の点数が変わることを確認

Webダッシュボード側は自動更新されるため、通常はブラウザの更新ボタンを押さなくても最新の点数を確認できます。

## カメラ読み取りについて

画面内の4〜6桁の数字を点数候補として拾います。
その数字の中心位置が、席ごとに設定した認識範囲に入っている場合だけ、その席の点数として反映します。

カメラプレビューは中央を正方形に切り取って表示します。
認識範囲は、その正方形画像の中で `中心X / 中心Y / 幅 / 高さ` を%指定します。
左上が `中心X=0, 中心Y=0`、右下が `中心X=100, 中心Y=100` です。
カメラ画像上には、席1〜4の範囲が色付きの四角で表示されます。
対角線の波線も表示されるため、麻雀卓の中心とカメラ画角の中心を合わせる目印にできます。
数値を変更すると四角の位置も更新されます。

初期値は以下です。

```text
席1: 上側中央  中心X=50 中心Y=4   幅=28 高さ=8
席2: 右側中央  中心X=96 中心Y=50  幅=8  高さ=28
席3: 下側中央  中心X=50 中心Y=96  幅=28 高さ=8
席4: 左側中央  中心X=4  中心Y=50  幅=8  高さ=28
```

この初期値は、上・右・下・左に赤い点数表示がある麻雀卓画像を基準にしています。
実際の卓・端末の向きに合わせて、各席の赤い点数表示が四角内に入るよう調整してください。
四角を横へ動かしたい場合は `中心X`、上下へ動かしたい場合は `中心Y` を変えます。
読み取り後は必ず席1〜4の入力欄を確認してから送信してください。
